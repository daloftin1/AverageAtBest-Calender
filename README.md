# Average at Best Calendar

Python 3.12 or newer is required. Install the dependencies in your local virtual environment with `python -m pip install -r requirements.txt`.

The **Holidays** filter shows only U.S. federal holidays as all-day entries, with observed dates labeled separately. **ALL** shows regular events and holidays by default. Use **Hide holidays** or **Show holidays** in ALL to change that view. The browser saves the preference separately for each signed-in account.

Run `python manage.py test` for Django tests and `node --test calendar_app/reminders.test.cjs` for reminder tests.
